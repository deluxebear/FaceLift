# 视频转实况照片

FaceLift 的“动态壁纸”工作区把本地视频转换成实况照片（Live Photo）。
转换、预览和导出均在 Mac 上完成，不需要连接 iPhone，也不使用 AirLift。

## 使用流程

1. 在侧边栏选择“动态壁纸”，点击“选择视频…”或拖入视频。
2. 选择 0.5–3 秒的片段与片段内的封面帧。
3. 选择屏幕比例，调整缩放、水平位置和垂直位置。
4. 点击“生成实况照片”。FaceLift 会生成无声 HEVC 视频和 JPEG 封面，
   并用 `PHLivePhoto` 校验它们能组成实况照片。
5. 点击“存入 Mac 照片”。仅在此时请求添加照片的权限；每次生成的成品
   成功保存后，不会再次提供重复保存按钮。
6. 如果 Mac 和 iPhone 使用同一 Apple 账户并开启 iCloud 照片，等待同步。
   也可以在 Mac“照片”中分享实况照片，并确认 iPhone 收到的是一张实况照片。
7. 在 iPhone 打开“设置 → 墙纸 → 添加新墙纸 → 照片 → 实况照片”，开启播放。
   实况墙纸在唤醒锁屏时播放一次，然后停在封面帧；不支持持续循环播放。

FaceLift 不会检测或报告 iCloud 同步完成，也不会直接设置 iPhone 墙纸。
“导出配对文件…”会在所选位置创建新的子文件夹，保留 JPEG 与 MOV 原始资源。
这两个文件用于备份；分别传送文件不等于传送一张实况照片。

## 当前验证范围

自动化测试覆盖实际视频编码、片段时间、裁切、旋转轨道、封面像素、配对标识、
逐帧墙纸元数据、封面时间与变换元数据、`PHLivePhoto` 格式校验、导出防覆盖，以及取消后的临时文件清理。
测试不会申请照片图库权限或向用户图库写入内容。

**格式校验通过不代表 iOS 一定允许锁屏动态播放。** 用户已确认本次成品可在
iPhone 照片中播放，并在唤醒锁屏时播放一次；其他素材和系统版本仍需验证。

目前不宣称任意视频或任意 iOS 版本均可生成动态墙纸。如果 iPhone 提示动态效果
不可用，应保留生成结果用于调查，而不是将 Mac 预览播放作为墙纸兼容的依据。

## 开发验证

```sh
python3 -m pytest tests/test_live_photo_converter.py tests/test_localization.py -q
```

转换模块只依赖系统框架。输出采用 SDR Rec.709、60 fps、1080×2340 或
1080×1920；输入格式以 AVFoundation 能否解码为准。预览和转换使用相同的
裁切变换，封面直接从转换后的影片提取。所有选项变更都会使旧成品失效，
防止将旧裁切或旧封面存入图库。取消转换与清除草稿都会清理临时资源。

## “动态效果不可用”的修复

旧版只写配对 UUID 和 `still-image-time`，可以通过 Mac 的实况照片格式校验，
但缺少墙纸参考实现使用的 `live-photo-info` 和封面变换轨道。当前版本补齐这两类
元数据，并使用 HEVC / 60 fps。封面时间标记采用 -1；裁切已烘焙进图像与视频，
所以封面变换为单位矩阵。默认选择 1 秒、1080×1920 的片段，仍可修改裁切与时长。

逐帧数据来自随应用打包的固定兼容模板，不代表原视频的真实运动传感器数据。
保留模板的格式描述与私有 setup data，按输出帧时序写入；不会拷贝模板的画面、
音频、配对 UUID 或原始封面时间。来源与许可见
[Resources/LivePhoto/README.md](../Resources/LivePhoto/README.md)。

旧成品不会自动更新，需要使用新构建重新生成并存入照片。
这次修复通过文件结构和真实编码回归测试，并已用用户原视频重新生成、实际存入 Mac 照片。
新成品 MOV 包含 57 个固定 `live-photo-info` 样本以及同轨的 -1 封面标记和单位变换。
完整测试为 54 项通过、6 项因旧测试素材缺失跳过。用户已确认新成品在 iPhone 照片中可播放、唤醒锁屏时播放一次。
这条反馈只覆盖该素材和用户设备，不代表所有视频和 iOS 版本均兼容。
